# Dawn Pet 生成检查表

## 身份一致性

- [ ] 头与身体是否是一整块连续、矮胖的黑色形体？
- [ ] 是否没有脖子、独立头部、细腰或蚂蚁式分节？
- [ ] 是否恰好两只小白圆眼，并有轻微高低或间距差？
- [ ] 眼睛是否位于整体上三分之一，且没有嘴、瞳孔、眉毛或腮红？
- [ ] 手臂和腿是否足够短、圆钝？
- [ ] 双脚是否扁平、略大，保持笨重站姿？
- [ ] 橙红色小半圆是否位于下腹正中，尺寸足够小？

## 风格与构图

- [ ] 背景是否纯白，并保留了足够留白？
- [ ] 角色是否为纯黑实心块，没有渐变、光泽、纹理或阴影？
- [ ] 道具是否仅用清晰、稀疏、略抖的细黑线表现？
- [ ] 是否只有一个核心动作和一个主要道具？
- [ ] 动作是否认真、笨拙、略带蠢萌，而不是靠甜美表情卖萌？
- [ ] 是否没有文字、标签、徽标、边框或水印？

## 流程图解一致性（仅当本张图是流程图时检查）

- [ ] 每个节点是否是**同一个** Dawn Pet（同样的矮胖黑团、两只错位白眼、短肢扁脚、橙红肚标），只是动作 / 道具不同？
- [ ] 每个节点的动作是否对应该节点的流程语义（查 flow-diagram.md 映射表），而非抽象图标？
- [ ] 是否没有用齿轮、云、数据库圆柱体等写实图标代替动作？
- [ ] 节点之间的箭头是否是稀疏细黑线、方向无歧义、且没有交叉？
- [ ] 是否只采用了一种布局（横向 / 分格 / 循环 / 分支），没有混排？
- [ ] 每个节点的标签是否在角色**之外**、节点正下方，且为手写短词（中 ≤ 4 字 / 英 ≤ 2 词）？
- [ ] 除节点标签外，是否没有标题、图例、边框、序号圆圈、水印？
- [ ] 节点数是否 ≤ 6（甜区 3–5），且保留了足够留白？
- [ ] 如果节点 > 6 或需要精确数值 / 表格 / 代码，是否应改用 mermaid 而非硬画？

## 失败信号

- 独立圆头或窄脖子让角色像蚂蚁。
- 身体过瘦、四肢过长，失去矮胖重量感。
- 出现嘴、眉毛、腮红、大眼高光或复杂表情。
- 角色变成机器人、鸟、兔子或带角/耳朵/天线的生物。
- 画面像精细矢量图、3D 玩具、信息图或密集流程图。
- 背景复杂、色彩过多或道具抢过角色。

## 修正顺序

1. 先修正一体化矮胖轮廓。
2. 再修正两只白眼、短肢、扁脚和下腹标记。
3. 再修正认真而笨拙的动作。
4. 最后简化道具、线条和留白。
