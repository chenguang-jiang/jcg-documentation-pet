# Dawn Pet 视觉系统

## 核心方向

采用白纸上的极简手绘漫画感：大面积留白、一个实心黑色角色、极少量细线道具，以及下腹唯一的橙红色小色块。整体应简明、直接、有动作冲击力。

可以借鉴开源 GitHub 插画中稀疏、轻松的白底手绘编辑插画语言，但不得复刻其他仓库的吉祥物、具体场景或成品构图。

## 色彩

- 背景：纯白。
- 角色：纯黑。
- 眼睛：纯白。
- 下腹标记：单一橙红色。
- 不使用灰阶、阴影、纹理、渐变、彩色环境或第二强调色。

## 线条

- Dawn Pet 本体以黑色实心轮廓为主，不依赖外描边。
- 箱子、桌椅、文件、箭头等道具使用纤细、略有手抖感的黑色线条。
- 线条要有手绘气息，但不要过细到缩小后消失。
- 少量动作线可以增强笨拙感，不能堆成视觉噪音。

## 构图

- 每张图只保留一个核心动作和一个主要道具。
- 角色必须是视觉焦点，道具只服务于动作叙事。
- 四周保留充足白边，不铺满背景，不做密集流程图或 PPT 式标注。
- 默认不放文字、标题、标签、水印或界面元素。

### 头像或主视觉

- 使用方形或横向白底画布。
- 单角色完整入镜，黑色轮廓清晰，眼睛和下腹标记可辨。

### 动作设定图

- 横向白底画布，最多三个姿势。
- 姿势之间留出明显空隙，不重叠、不连接成连续背景。
- 每个姿势的身体宽高、眼睛、短肢和下腹标记保持一致。

### 正文场景配图

- 默认 16:9。
- 优先选择搬、推、接、够、跌倒、坐倒等一眼可懂的动作。
- 道具可以夸张偏大，以增强小角色认真努力却力不从心的反差。

## 可爱感的来源

- 矮胖比例、短肢、扁脚和略不对称轮廓。
- 认真空白的眼神与笨拙动作之间的反差。
- 动作发生前后的一瞬停顿，而不是婴儿脸或甜美装饰。

## 常见失败

- 把头画成独立的小圆球，导致像蚂蚁。
- 身体收腰、四肢变细长，失去黑团重量感。
- 轮廓过于规整、像光滑矢量图标。
- 道具线条太密、太细或机械制图化。
- 添加嘴、眉毛、腮红或大眼高光来强行卖萌。
- 回退到红色圆顶机器人、鸟形或无脸抽象生物。
